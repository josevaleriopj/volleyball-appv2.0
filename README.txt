# Volleyball Coach iPad App

This is a ready-to-use iPad/iPhone-friendly web app.

## How to use on iPad

1. Upload this folder to Vercel, Netlify, GitHub Pages, or any web host.
2. Open the link in Safari on your iPad.
3. Tap the Share button.
4. Tap "Add to Home Screen".
5. Open it from your iPad Home Screen like an app.

## Included functions

- Clean volleyball court
- Drawing board with pen, eraser, undo, and clear
- 12 home players
- Editable names and positions
- Stats tracking
- Score tracking
- Save/load on the same device
- Mobile/iPad touch-friendly layout
- Offline cache after first load
